Komponen Column luar yang memenuhi seluruh layar dengan Modifier.fillMaxSize() meratakan seluruh elemen ke tengah secara horizontal dan vertikal. Di dalamnya terdapat Column kedua yang berfungsi sebagai kartu profil, menggunakan modifier clip(RoundedCornerShape(32.dp)) untuk membuat sudut melengkung, .background(Color(0xFFD3C8D5)) untuk warna latar belakang ungu muda, dan .padding(32.dp) untuk memberi jarak dalam. Di dalam kartu tersebut, Image foto profil diatur ukurannya menggunakan Modifier.size(120.dp) dan dibulatkan dengan .clip(CircleShape). Selanjutnya, terdapat komponen Text untuk nama, NIM, dan program studi yang diselingi oleh Spacer dengan modifier tinggi bervariasi (height(8.dp) dan height(4.dp)) guna mengatur jarak vertikal antar teks. Setelah kartu profil, Spacer dengan Modifier.height(12.dp) diselipkan sebelum memanggil fungsi kustom FollowButton(), yang berisi sebuah Button interaktif dengan state reaktif untuk mengubah teks tombol secara dinamis antara "Follow" dan "Unfollow" ketika ditekan.

Pendekatan deklaratif pada Jetpack Compose memangkas kompleksitas pengembangan seluler secara drastis dibandingkan XML tradisional seperti LinearLayout. XML memisahkan struktur UI dan logika ke dalam file XML dan file Kotlin terpisah yang memerlukan manipulasi manual menggunakan findViewById, sedangkan Compose memungkinkan kita menyusun antarmuka dan state langsung dalam kode Kotlin murni yang ringkas. Hal ini menghilangkan kode boilerplate yang panjang dan mengurangi risiko bug akibat ketidaksinkronan antara data di memori dan tampilan visual di layar, sekaligus didukung sistem Modifier yang membuat pengelolaan tata letak, warna, dan dekorasi menjadi jauh lebih efisien.
