### Penjelasan singkat kode
Aplikasi ini terdiri dari tiga komponen utama yang memanfaatkan state untuk memperbarui UI secara otomatis. Pada CounterPlusMinusApp, state count digunakan untuk menyimpan angka, di mana tombol kurang (–) diberi validasi if (count > 0) agar nilainya tidak pernah berkurang di bawah nol. Komponen ToggleColorBox menggunakan state boolean isRed yang dipadukan dengan modifier .clickable untuk mengubah warna Box secara bergantian antara merah dan hijau setiap kali diklik. Sementara itu, pada InteractiveProfileCard, state isFollowed mengontrol dua elemen UI sekaligus secara bersamaan, yaitu memperbarui teks pada tombol ("Follow"/"Unfollow") dan mengubah status teks indikator di bawahnya ("Anda mengikuti akun ini"/"Anda belum mengikuti akun ini").

### Analisis singkat keuntungan Compose dibandingkan XML layout
Jetpack Compose menawarkan keunggulan utama melalui pendekatan UI Deklaratif, di mana tampilan secara otomatis memperbarui dirinya (recomposition) mengikuti perubahan data (state), sehingga mengeliminasi kode imperatif manual seperti setText() atau setBackgroundColor(). Selain itu, Compose menyatukan logika antarmuka dan state dalam satu bahasa (Kotlin) tanpa perlu mengelola berkas XML terpisah, pemanggilan findViewById(), atau View Binding. Komponen UI pada Compose disusun menggunakan fungsi biasa (@Composable) yang sangat modular, mudah digunakan kembali, dan efisien secara performa karena Compose hanya akan menggambar ulang (re-render) bagian UI spesifik yang membaca state yang berubah.
